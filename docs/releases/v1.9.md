# Refresh All Tabs 1.9

First GitHub release of the Chromium Manifest V3 extension.

## Highlights

- Refresh tabs manually or on a timer (1 to 1440 minutes).
- Four refresh modes: all tabs, all except the active tab, the current window, or the active tab only.
- Per-site domain exclusions work in **all four modes**, including timer-triggered refreshes.
- Domains match their subdomains but not lookalike domains. Existing settings are retained on upgrades from 1.6-1.8.
- Fixes for an unavailable active tab, error handling, interval validation, and the localized options page title.
- 19 interface languages, including Russian and English.

## Installation

1. Download `RefreshAllTabs.1.9.zip` below.
2. Extract it to a permanent directory.
3. Open `chrome://extensions` (or the equivalent page in your Chromium browser), enable **Developer mode**, and select **Load unpacked**.
4. Choose the extracted folder containing `manifest.json`.

For an existing unpacked installation, replace the extension files in the **same folder**, then click **Reload** on the extensions page to preserve the extension ID and saved settings.

## Verification and limitations

- JavaScript syntax checks, 41 automated regression tests, package validation and ZIP integrity checks are run by GitHub Actions before publication.
- A real installed-extension acceptance check in Comet is still required. Browser-automation checks with a mocked extension API are not equivalent to running the extension in Comet.
- No analytics, remote server, or third-party runtime dependencies.
- Automatic refresh timing depends on Chromium alarms and may be delayed during sleep or browser suspension.
- Refreshing tabs can discard unsaved page content. Exclude sites containing work you want to preserve.

The downloadable `SHA256SUMS.txt` contains the digest of the release ZIP.

See [README](https://github.com/StanleyLl0yd/RefreshAllTabs#readme) for usage, permissions and limitations.
